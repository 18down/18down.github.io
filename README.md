# Memoirs of a Sinner

The website of **18 Down** — Charl Jordaan, composer and multi-instrumentalist.

Live at **https://18down.co.za**

## What is in here

This repository *is* the website. Every file in it is served exactly as it
sits here — there is no build step and nothing to install.

| Folder | What it holds |
|---|---|
| `index.html` | The home page |
| `pages/` | About, Images, Music, Links |
| `blog/` | The journal — 616 entries, May 2014 to August 2026 |
| `assets/` | Styling, fonts, photographs, the two small scripts |

## Editing it

`blog/` is **generated**. Editing a file in there is wasted work — it is
rebuilt from the original WordPress export and anything typed into it by hand
is overwritten. The other pages are ordinary HTML and can be edited directly.

`COPY-ME-new-page.html` is a blank page to copy when adding a new one.
